# Java Backend Review Defaults

- Follow the current codebase's Java version and patterns.
- Prefer readable, testable solutions over needless abstraction.
- Review transaction safety, concurrency, null safety, error handling, logging and sensitive data.
- For audit logging, check old/new value consistency, rollback behavior, field-level data exposure and reflection overhead.
- For distributed systems, review idempotency, retries, timeouts and consistency.
- These are suggested defaults, not verified personal coding conventions.
