# Personal Codex setup

Shared rules and setup backup for Bryan's Codex devices.

On another laptop, clone/download this private repo, open it in Codex, and say:

> Set up this laptop using this repo.

See setup/SETUP.md for the procedure and current limitations.

- AGENTS.md, PROFILE.md and preferences/: personal instructions and preferences.
- setup/POLICY.md: inspect skills/plugins before installation and save verified changes back to this repo.
- skills/, plugins/, mcp/: destinations for reviewed inventories, skill backups and sanitized connection templates.
- installations/: verified installation history per device.
- audits/: review summaries and explicit exceptions.
- setup/ROADMAP.md: remaining work for complete restoration and syncing.

The instructions are ready; full automatic restore/sync and the Mac's prepared skill bundle are not included yet. Rules must be merged into each device's effective Codex user instructions to apply beyond this repository. Credentials require separate login on each device.
