Review scope: an authorized read-only research agent read the complete Superpowers SDD SKILL.md; complete Planning with Files Codex SKILL.md and selected generic sections; complete Task Master README, orchestrator and license; complete Beads README, packaged SKILL.md and license. Supporting runtimes/scripts/dependencies were not fully audited or executed. Superpowers, Planning with Files and Beads declare MIT; model/tool usage and integration costs remain task-dependent and unmeasured.

Planning with Files' Codex variant contains shell hooks and assumes host paths; session-history access instructions differ in explicitness between variants. Do not import it blindly. Beads' former steveyegge repository redirects to gastownhall/beads. Task Master's context-size estimates are upstream claims, not measurements made here.

The local core records the brief, proposal digest, real user confirmation evidence, roles, readiness, task dependencies, actual actors, blockers, results and verification. A changed brief or combination invalidates confirmation. The ledger enforces its own state transitions but cannot authenticate the user, launch a model or prove output quality. The assistant still checks real artifacts and respects host permissions. It publishes only sanitized lessons, not the project's raw task state.
