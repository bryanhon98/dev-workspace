# Global skills backup

Save personal skill sources under custom/<name>/ and redistributable third-party sources under external/<name>/ with required licenses. Keep drafts outside active discovery directories until testing and inspection finish. Every skill, including a custom skill, goes through the creator workflow when edited and SkillSpector before activation.

Install both kinds in user scope by default (currently ~/.agents/skills/<name>/), not inside a project, unless explicitly requested. Record exact versions/hashes in inventory.json and review evidence in audits/. No skill payloads have been imported yet.
