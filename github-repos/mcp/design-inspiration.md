**Distinct job:** Search and compare real award-winning site references with screenshots, palettes and tech stacks; prepare evidence-linked design briefs. Optional browser tools can inspect live page structure, scrolling/motion, visual components, network/performance clues and even WebGL/3D canvas poses. This can complement a design *skill* (which guides decisions); it does not independently guarantee good design.

**Overlap:** Existing saved `juliobsz/skills` **awwwards**/**jury** are instruction-based website build/review methods, not this MCP data/research server; standard browser tooling (Playwright, Chrome DevTools) overlaps live page capture and QA. Choose the lightest source that provides the missing evidence and avoid simultaneously exposing several browser automation tools without need.

**Prerequisites and security considerations:** The documented no-account/basic mode requires Node >=22.13 and starts a local `npx` MCP server; its own README says browser-capture tools **do not work in the isolated npx install** without side-by-side Playwright and ffmpeg packages. A global browser-enabled install adds executable dependencies and wide website/browser access; require explicit approval and review of the actual package and permissions, host setup and external-data terms. It periodically checks for npm updates and documents opt-in self-update; do **not** enable auto-update. Basic site searches/screenshot reference pages are claimed free/no API key by the author; normal agent/model/runtime resources still apply. Live capture may fetch third-party website code; inspect permitted scope and never treat captured logos, visuals or scripts as licensed production assets. The README says the server uses rate-limited publicly available Awwwards data and a local cache, **not** privileged access to Awwwards.

**Companion project:** Its author publishes optional `awwwards-skills` in a **separate** [repository](https://github.com/INSANE0777/awwwards-skills); those are not bundled into this MCP, and no companion skill was selected or installed here.
