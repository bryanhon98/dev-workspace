## [Context Mode](https://github.com/mksglu/context-mode)

Optional for repeated large tool outputs: filter, index and retrieve relevant pieces instead of adding everything to context.

Codex behavior is version-dependent; source includes newer hooks beyond stale README wording. Measure benefit against existing selective tools. Advertised 98% savings is not a universal bill reduction, and retrieval can omit evidence. Local indexes are not setup backups.

**Cost and license:** Elastic License 2.0, not a permissive MIT-style license; self-hosted use is available, but hosted/managed redistribution restrictions matter. Requires a local runtime and storage.

## [PhotoCraft](https://github.com/storytold/photocraft)

Optional local layer-based image editing, masks, CLI batching and MCP control; useful for actual editable image operations.

Early alpha, not established Photoshop parity. Use document copies: batches are not atomic and saves can overwrite. It adds a native editor/runtime; the existing image-generation tool may suffice for simpler work.

**Cost and license:** MIT OR Apache-2.0 for code; separate asset/brand licenses apply. Core local editing has no mandatory hosted account/API cost. Installation and disk/runtime requirements remain a separate review.
