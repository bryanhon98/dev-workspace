## [Cloudflare Security Audit](https://github.com/cloudflare/security-audit-skill)

Use for a scoped security investigation needing evidence records, coverage accounting and separate verification of proposed findings.

Conditional, with a budget. A small competitor-authored comparison found equal median recall to plain review at much higher cost; that is a caution, not a universal verdict. This is not dependency-advisory coverage or a SkillSpector replacement.

**Cost and license:** MIT; no required Cloudflare account. Multiple recon/hunter/critic/verifier calls can be costly. User report #20: on one seeded target, three rounds per arm at same model tier/budget class, quick median $29.95 vs plain-agent $2.06; exact model not named in retrieved issue body. Not a pricing forecast.
