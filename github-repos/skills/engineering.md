## [shadcn/improve — codebase audit and executable plans](https://github.com/shadcn/improve)

**Library status (2026-11-15):** User-saved **optional research candidate only**; not installed, executed, activated, SkillSpector-scanned or added to the three mandatory Tool Advisor skills. Verified official upstream revision `cac56e1ebd3c279aa9153616cfeac7b174ab90f9` (2026-09-12). The skill is general software engineering review, **not** a shadcn/ui component-styling feature.

**Distinct capability:** Review a repository, check correctness/security/performance/tests/technical debt/architecture and other relevant categories, independently validate file-and-line evidence, prioritize findings, and write self-contained implementation plans for a separate executor. Plans include exact repo commands, acceptance checks, stopping conditions, current code references and scope restrictions. Useful when a less capable Codex model must execute a precisely specified, verified change. `quick`, `deep`, `branch`, `security`, `plan`, `review-plan` and `reconcile` are documented modes; optional `execute` delegates work to a separate agent in an isolated Git worktree.

**Overlap / selection:** Tool Advisor already coordinates requirement discovery, planning, delegation, implementation and independent review. Use Improve only if its **bounded evidence-driven audit or high-precision handoff plan** adds value; never give it a second project coordinator role or make it mandatory. For small well-specified tasks, existing focused review/plan is usually simpler. Its `execute` mode may spawn workers and its `--issues` mode can publish information on GitHub; obtain explicit user approval, honor host capabilities and existing scope gates, and check for public disclosure of security findings before any issue creation.

**Cost / runtime / security:** Skill metadata and the bundled licence file state MIT. Requires an Agent Skills-capable host, repository read access and the model/agent budget appropriate for review; actual cheap-model selection and independent worker execution are **host-dependent, not automatic**. The skill documents read-only source auditing but writes plans and can trigger controlled executor-worktree actions when explicitly requested. SkillSpector scan of the *exact* revision and separate checks of tool permissions are required before use. No benchmarks independently reproduced.
