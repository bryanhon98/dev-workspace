## [Corey Haines Marketing Skills](https://github.com/coreyhaines31/marketingskills)

Choose product-marketing, customer-research, copywriting/copy-editing and the SEO/CRO child needed for your project. One parent entry covers the collection.

Native Codex packaging exists. Start with a small subset of the 50 skills. Optional service wrappers can publish or delete content; choosing a writing skill does not authorize those actions. Sponsored integrations are not independent endorsements.

**Cost and license:** MIT. No license fee; Codex/model use costs remain. Optional marketing services, API calls and ads have their own fees. Verified Partner integrations are disclosed sponsorships.

## [Humanizer](https://github.com/blader/humanizer)

Use explicitly to edit an important draft for repetitive phrasing and unnatural patterns, preferably with a voice sample.

Optional editing tool, never global communication rules. Its source preserves claims, which does not fact-check an inaccurate draft. External evaluation found modest style gains and extra usage, not a guarantee of authorship detection or better writing in every case.

**Cost and license:** MIT; model context/output usage only, no separate tool fee. Large instruction file can cost more than a concise rewrite prompt.

## [Claude SEO](https://github.com/AgriciDaniel/claude-seo)

Consider for recurring technical SEO audits that need rendered-page collection, structured reports and optional live SEO data.

Conditional: the workflow is Claude-oriented and needs Codex adaptation plus Python/browser dependencies. For a light check, start with the marketing collection. Scores do not prove ranking gains; older SPA/GEO reports must be checked against current fixes.

**Cost and license:** MIT core; FLOW reference material is identified separately as CC BY 4.0. Model usage, Python/browser setup and optional paid DataForSEO/SEO data subscriptions remain. Google APIs require configured keys/OAuth and relevant access/quotas.

## [Instagram Agent Skills](https://github.com/Jakeschincariol/instagram-agent-skill)

Optional if Instagram becomes a regular workflow: use reel structure, caption checks and account-relative example ranking rather than raw follower counts.

One parent entry, not thirteen separate installs. Author hook results are weak screening evidence, not a virality predictor. Generic rewriting overlaps Humanizer; inspect multilingual text after regex edits. Independent growth uplift is unestablished.

**Cost and license:** MIT; helpers have no API fee or required third-party Python dependencies in inspected imports. Model use costs remain; live research is separate.
