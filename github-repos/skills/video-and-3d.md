## [Hyperframes](https://github.com/heygen-com/hyperframes)

HTML/CSS and seekable-animation video framework with production skills, CLI, browser preview and MP4 rendering.

Local CLI needs Node22+ and FFmpeg; rendering uses headless Chrome. Open-source engine and optional Pro/cloud features have different requirements/costs. Useful for rendered video and motion graphics; not by itself an arbitrary interactive 3D model viewer. Match selected skills to the CLI release before later installation.
