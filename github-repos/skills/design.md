## [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)

Optional local search across typography, palettes, interface patterns and stack guidance; useful when choosing an initial design system.

A searchable reference collection adds more than another general art-director prompt. Recommendations are heuristics. Mac/Codex installation reports require a target-device check; no installation was tested here.

**Cost and license:** MIT. Core local searches need no model API or subscription; the coding agent still consumes model usage. Font/icon assets have their own licenses.

## [Taste — BrandKit and Image-to-Code only](https://github.com/Leonxlnx/taste-skill)

Preserve your selected children under one parent: BrandKit produces a repeatable identity board; Image-to-Code develops visual section references and then implements them.

Explicit use only. Image-to-Code prescribes image generation per section and detail retries, which adds usage. Its workflow can conflict with simply implementing an existing design. The default v2 and other variants are not shortlisted.

**Cost and license:** MIT; normal image/model usage and external asset terms apply. Image-to-Code prescribes roughly one generated image per section plus fresh detail images/retries, so usage can grow substantially. The README's 30–45-minute/hundreds-of-thousands-token estimate describes default v2, not these children.

## [Extract Design System](https://github.com/arvindrk/extract-design-system)

Extract starter colors, spacing, typography and other exposed design tokens from a website into a local project.

Optional for an extraction task. It needs browser/executable dependencies; a copied SKILL.md alone is insufficient. DOM/CSS tokens are not a complete semantic component system. Preserve source asset and font terms.

**Cost and license:** MIT. No mandatory model API or paid extraction service established in inspected code; network/browser installation and normal agent usage apply. Extracted websites' fonts, logos and assets retain their terms.
