## [Astryx by Meta — React design system](https://github.com/meta/astryx)

**Status:** Saved on 2026-11-10 as a user-selected library candidate only. **Not installed, security-scanned, approved for activation, or added to `inventory.json` or the 17-skill baseline.** This is a component library, not an agent skill or Codex/Claude plugin.

**Purpose and fit:** Open-source design system for React 19+ applications, built using StyleX. Provides accessible UI components, themes, dark mode, templates, and CLI/agent-oriented documentation. Evaluate it when implementing a new React frontend or standardizing an existing React UI; it is not needed for a Java/Spring Boot backend alone.

**Caveats:** Currently in beta. Adoption requires a compatible React frontend and project-level dependency review, accessibility/visual testing and license verification for any third-party assets. A saved link is not evidence that a target project is compatible or that its executable packages have passed a security check.
