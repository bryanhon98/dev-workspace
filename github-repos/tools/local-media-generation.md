## [WanGP (formerly Wan2GP) — deepbeepmeep](https://github.com/deepbeepmeep/WanGP)

**Library status (2026-11-13):** User-requested optional reference, **not installed, activated, benchmarked or security-approved**. No default Tool Advisor skill or inventory changes. The former repository URL `deepbeepmeep/Wan2GP` redirects to `deepbeepmeep/WanGP`; prefer the latter canonical address.

**Classification:** Local, multi-model generative-media **software / runtime with browser interface, API and MCP interface**, not one generative model and not by itself a Codex/Claude skill. The project currently lists Wan 2.1/2.2, LTX-2 variants, MiniMax H3 and Hunyuan Video for video, alongside image, audio, 3D and interactive-world models. Model compatibility, restrictions and required resources are model- and configuration-specific; upstream's broad model catalog does not prove all combinations work on a user's device.

**Why consider it:** Run compatible video/image models **on the user's own GPU**, potentially avoiding recurring cloud-per-generation charges. Compare to cloud services when video quality, speed, cloud model availability or convenience dominates; compare with other local generative runners when local control, privacy and repeated generation matters. WanGP exposes an MCP interface for agent automation, but that **does not mean installing the app automatically installs a skill or connects it to Claude Code/Codex**. Separate host configuration, network exposure checks and genuine end-to-end validation are required.

**Hardware and setup:** Official documentation claims *selected* configurations/models can run with as little as **4 GB VRAM** and lists GTX 10xx / RTX 20xx+ NVIDIA generations plus specified AMD RDNA generations. This is **not** a universal minimum for every video model, quality setting or workflow. Large videos/model weights can need substantially more GPU VRAM, system RAM, disk storage and time. Verify the actual GPU first (`nvidia-smi --query-gpu=name,memory.total --format=csv` on NVIDIA systems), then the chosen model's exact resources. Very old/2 GB GPUs are not implied to be supported by the 4 GB headline. On Windows the author supplies an experimental guided **WanGP Manager** and `scripts/install.bat` / `scripts/run.bat`; scripts can install Python, Git, PyTorch and other binaries/packages. The manual installation instructions distinguish CUDA/driver/PyTorch combinations. **Not zero-configuration or universally plug-and-play.**

**Security / privacy / costs:** Local inference ordinarily avoids sending generation inputs to a cloud inference provider, but the application includes optional network/model downloads, optional agent/web features, local APIs and an MCP interface: confirm endpoint binding, permissions, remote use, enabled add-ons, model-provenance and dependencies before use. The installer script contains optional PowerShell download-and-execute setup paths for dependencies; do **not** run it automatically just because this repo is in the library. SkillSpector is a skill-focused scan, **not** a complete malware/supply-chain audit of Python packages, GPU drivers, model weights or executable installers. Local software has no per-generation cloud API fee when fully local; GPU hardware, power, disk, and any explicitly selected remote services may cost money.

**Licence — important distinction:** [WanGP Community License 2.0](https://github.com/deepbeepmeep/WanGP/blob/c8d47da27023476777a0874300bbc9a4126acca6/LICENSE.txt) is a **custom, source-available licence**, not standard MIT/Apache or assumed unrestricted open source. Its summary permits free local personal/work use and use/sale of generated outputs subject to applicable terms; it restricts selling/repackaging WanGP or offering paid hosted/API/SaaS access without a separate agreement. Third-party model weights/code have **their own licences**. Review full binding terms before commercial redistribution, service operation or use of third-party outputs.

**Alternatives and overlap:** [Open Generative AI](https://github.com/Anil-matcha/Open-Generative-AI) can use WanGP/Wan2GP as a separately installed *local* inference backend; Open Generative AI also provides a distinct MuAPI-based cloud path that may consume paid credits. Other already-cataloged video tools include [Hyperframes](../skills/video-and-3d.md#hyperframes) for code-driven motion-graphics rendering and [Watch](documents-and-video.md#watch-claude-video) for *analysis* of existing footage; neither is a drop-in local diffusion video model runner. Avoid conflating generation, editing and analysis capabilities.
