## [Claude Code Router](https://github.com/musistudio/claude-code-router)

The selected gateway candidate if you need multiple providers, retries, ordered fallback and separate agent profiles. Current v3 includes Codex CLI and app support.

Optional service, not a skill and not required for normal Codex. Do not stack it with OmniRoute and FreeLLMAPI. Check streaming, tool calls, credentials and profile rollback on the target device; historical desktop integration issues do not prove current failure.

**Cost and license:** MIT code; provider API/subscription charges and eligibility remain separate. Estimated cost displays do not guarantee cheaper or equivalent model behavior.
